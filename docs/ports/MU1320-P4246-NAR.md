# MHI2Q P4246 / MU1320 NAR compatibility port

Compatibility port for early NAR Audi MHI2Q systems running MU1320.

## Vehicle-tested configuration

- Vehicle: Audi Q5 (FY), MY2018
- Region: NAR / USA
- Firmware train: `MHI2Q_US_AUG22_P4246`
- MU software: `1320`
- Head-unit part number: `8W5035880D`
- Hardware revision: `034`
- Virtual Cockpit: `KI_FPK_AU491`
- Factory Apple CarPlay

Base upstream revision:

`404ccc23450e385a0183d37fc93677a0c9a5637d`

## Why MU1320 needs a compatibility port

MU1320 differs from the later MHI2Q Java/HMI interfaces used by the original
MU1316/MU1329 implementation.

The port adapts:

- `ExternalEventsListener`
- `CarplayDSILifecycleController`
- `HighPriorityResourceTracker`
- `PartialPopupManagerEvoHigh`

The changes cover differences in smartphone properties, DSI resource APIs,
resource-policy interfaces, emergency-call interfaces, and partial-popup
manager inheritance.

The patched Java bundle was linkage-audited against the MU1320 stock class set.

## P4246 SWDL bootstrap

On P4246, the SWDL FinalScript environment and the MMX node may not expose the
SD card through the same filesystem path.

The P4246 bootstrap therefore:

1. discovers the SD card from MMX;
2. mounts `/mnt/app` writable;
3. installs Toolbox scripts and GEM definitions;
4. verifies all required files;
5. cleans legacy Toolbox files;
6. remounts `/mnt/app` read-only;
7. reports success only after verification.

## P4246 Toolbox selection

If the SWDL screen shows `Toolbox [N]` and **Start update** is disabled:

1. Open M.I.B. -> Advanced Settings -> SWDL FW Updates.
2. Enable **User defined SWDL**.
3. Return to the software update screen.
4. Select **User defined**.
5. Enter the `Toolbox` component.
6. Select only the Toolbox payload.
7. Confirm that the parent Toolbox entry changes to `[Y]`.
8. Start the update.

Do not select unrelated NavDB, Eggnog, Truffles, SpeechResVDE, or other
firmware/database components.

## Build

Provide a stock Java archive obtained from your own MU1320 unit:

    STOCK_JAR=MU1320-base.jar ./scripts/build_sd.sh

Stock Audi firmware and unit-specific dumps are intentionally not distributed
by this repository.

## Installation sequence

After the Toolbox has been installed successfully:

1. Disconnect the iPhone.
2. Open GEM -> `mqbcoding`.
3. Run `MMI-Cockpit-Carplay -> INSTALL`.
4. Reboot the MMI completely.
5. Run `MMI-Cockpit-Carplay -> START`.
6. Reboot again.
7. Run `STATUS`.
8. Connect the iPhone and start CarPlay.
9. Start navigation and run `STATUS` again if diagnostics are required.

Use `RESTORE ORIGINAL` to return to the backed-up stock configuration.

## Safety

This project modifies files on the infotainment unit.

- Make a complete backup before installation.
- Keep the original stock backup in a safe location.
- Use a stable external 12 V supply during SWDL/programming.
- Do not cross-flash P4246 with P5087, P5092, or another firmware train.
- Do not assume compatibility solely from the MHI2Q designation.
- If SWDL reports a failed stage or download-client error, stop and diagnose
  the failure rather than repeatedly retrying.

## Not distributed

This repository does not distribute:

- Audi firmware packages
- stock `.jxe` images
- IFS images
- RCC dumps
- EEPROM dumps
- FEC containers
- vehicle-specific backups
- `backup.zip`
- stock MU1320 Java archives

Users must obtain required stock inputs from their own unit.
